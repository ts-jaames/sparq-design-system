GRAIN

Sparq's pattern language. How anything built on the capability model looks, behaves, and hands work between people and agents. One register for generated interfaces and the agents behind them, not a component library. Point an agent at the MCP server: it reads the rules before it builds, and the harness checks the work before it stops.

  1. Guardrails shape how a limit, a refusal, or an unknown reads to a person.
  2. Retrieval shows people where an answer came from.
  3. Agentic is how people and agents ask, hand off, and take back work.
  4. Interaction is how people see, review, edit, and undo what an agent made.
  5. Norms set how it should feel every time: tone, pace, and trust.
